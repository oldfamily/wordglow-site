# wordglow-site

Public pages for **Wordglow**, a free vocabulary test-prep app for grades 6–12.

Published with GitHub Pages:

| Page | URL |
| --- | --- |
| Home | https://oldfamily.github.io/wordglow-site/ |
| Privacy policy | https://oldfamily.github.io/wordglow-site/privacy-policy.html |
| Support & FAQ | https://oldfamily.github.io/wordglow-site/support.html |

The privacy policy and support URLs are referenced from the app's App Store
listing, so they need to stay reachable at these paths for as long as the app
is published. Renaming or deleting this repository breaks both links.

Source for these pages also lives in the app repo under `docs/store/`.
